# Apk3rade

تطبيق أندرويد (WebView) لمتجر Apk3rade: https://apk3rade.mangoad.online

المميزات:
- شاشة بداية بهوية المتجر + سحب للتحديث (معطّل في الرسائل ولوحات الإدارة والمطور)
- إخفاء رسالة "ثبّت التطبيق" نهائياً داخل التطبيق
- جلسة الدخول محفوظة، ورفع الملفات (APK/صور) شغال
- تحميل عبر مدير التحميل في أندرويد (بما فيها تحويلات archive.org / mediafire)
- إشعارات أندرويد للرسائل وطلبات الصداقة (فحص كل 15 دقيقة تقريباً)
- فتح روابط المتجر من أي مكان داخل التطبيق + مشاركة أصلية + فيديو بملء الشاشة
- زر رجوع ذكي، وضغطتين للخروج، وشاشة خطأ عند انقطاع النت

الإعدادات في AppConfig.kt

مميزات إضافية (1.2):
- زر إعدادات التطبيق في الهيدر: الإشعارات، قفل التطبيق (بصمة/رمز الهاتف)، إذن التثبيت، مسح الكاش، مشاركة التطبيق
- مركز تحديثات: يعرض التطبيقات المثبتة على الجهاز اللي ليها إصدار أحدث
- شارات "مثبّت / تحديث" وأزرار "فتح / تحديث" حسب المثبت على الجهاز
- تثبيت تلقائي بعد تحميل APK + اختصارات على الأيقونة
